# Laoshifu Diagram Glyphs

Fixed bitmap glyph subset generated from NotoSansCJKsc-Regular.otf (Noto Sans CJK SC, Noto Project). The derived bitmap set is named Laoshifu Diagram Glyphs and distributed under SIL Open Font License 1.1; see OFL.txt. The full source font is not shipped.

Original font copyright: © 2014-2021 Adobe (http://www.adobe.com/).

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese
Source font SHA256: 2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b

Generated at 56 px using Pillow, 64x80 grayscale masks with common baseline 60; JSON carries base64/zlib masks. Runtime needs only Python's standard library, not Pillow, a browser, a font installation, or a remote font server. These are chart-label glyphs, not a general purpose font or user-data capture. PNG has an opaque background so host dark mode cannot change the bars.
