# 内部推断方法

本文件只约束后台推断，不提供用户话术。用户输出遵循 [consultation-method.md](consultation-method.md)。

## 八字内部顺序

1. 以精确节气确定年、月柱，采用晚子时换日。
2. 以月令和格局确定主要组织方式。
3. 以旺衰判断承载财、官、食伤等议题的能力。
4. 以调候处理寒暖燥湿，不用"五行缺什么补什么"替代。
5. 以透干、藏干、刑冲合害定位表现方式。
6. 以大运和流年判断阶段主题，不从本命直接锁定具体事件。

## 紫微内部顺序

1. 主星本性与落宫主题。
2. 双星组合，不把两颗单星机械相加。
3. 对宫与三方，空宫尤其需要借照。
4. 吉煞修正，不覆盖主星。
5. 四化修正：资源、主导、名誉缓冲、牵挂阻力。
6. 限运触发，只放大议题，不单独锁定事件。

涉及算法未覆盖的完整庙旺落陷表、细分格局或流派口诀时，内部等级下调。

## 聚合（八字+紫微）

- `same`：同一具体议题、同一方向。
- `complementary`：一个解释内在动机，一个解释外部表现，可同时成立。
- `conflict`：同一议题出现相反方向，保留冲突并等待现实事实或时间条件区分。
- `single`：只有一个体系有足够证据。

不得为了制造双高同断而忽略反证。`high` 必须至少绑定一条内部 `high` 证据；同级直接反证存在时不得标记 `same`。

## 聚合（六爻+奇门）

算事时六爻和奇门各生成独立的内部证据链：

- `same`：同一具体议题（吉凶、方向、时间），两法指向相同结论。
- `complementary`：六爻给出动变趋势与旺衰判断，奇门给出空间方位与格局条件，可互补成立。
- `conflict`：同一议题出现相反方向。先检查输入（时间边界、起卦方式、节气前后）；若输入无误，记录冲突，出断时以 `probable` 或 `tentative` 说明两种可能。

六爻+奇门的双高同断规则：
- `agreement=same` 且 `liuyao_level=high` 且 `qimen_level=high` 且无同级反证 → `delivery` 强制为 `firm`。
- `firm` 时 verdict 必须直接断言不含"可能、大概、多半"等概率词。
- 奇门九宫、格局、用神绝不写入用户可见字段，只以内部 evidence ID 形式出现在 conclusions 中。

## 输出隔离

内部推断结果先写入 `consultation-plan` 或 `fusion.json`，再由校验器控制措辞。用户答复不得直接读取或复述本文件中的术语、体系名称和证据链。
