# 私有会谈：明确开启、告知、留存与清理

## 使用前

本文件只管理免费本地版生成的会谈工件，不管理聊天平台、云备份、用户导出的文件或托管付费订单。旧会谈目录不自动扫描/接管；旧文件如需处理，先由用户确认具体位置，不把它们混进新管理根目录。

先确认用户明确要传统测算；普通事业/感情/合同建议不足以授权。用户只看固定示例时不索要资料、不建个人会谈。

选择用户可控的本机私有根目录。Windows有合适D盘时优先该盘；目录须为全新路径，父目录已存在，不能位于源码/Git仓库或共享目录，不能含链接或junction。新建根目录仅做权限/标记，不保存出生资料：

```text
python <skill-root>/scripts/session_store.py init --base <私有根目录绝对路径>
python <skill-root>/scripts/session_store.py prepare --base <私有根目录绝对路径> --hours 24
```

默认24小时有效；用户明确需要多日追问，可在准备时选1—168小时。prepare只建立随机空会谈及存储规则，不接受个人输入。展示返回的实际 notice，至少包括实际保存位置、出生或私事/盘面/答复/复核/图像的保存范围、到期时间、没有后台自动删除，以及如何清理。示例口吻可短，但不能删掉实际路径、期限和清理事实。等用户明确同意保存并继续测算后，才执行：

```text
python <skill-root>/scripts/session_store.py confirm --session <返回的会谈绝对路径> --notice-sha256 <本次告知哈希> --explicit-request
```

不要为了执行命令自己代用户同意。CLI参数只记录宿主已取得的同意，不能证明用户实际看过。不同会谈不能复用同意；同一未过期会谈内不重复盘问。

## 正式测算

使用SKILL.md中的session_store.py run入口。它只调用本包固定真实出生/问事程序，固定输出到本次会谈；不能传--output或更换可执行程序。同一次已有盘面不再重起。后续先切换到该私有会谈目录，并始终用绝对技能路径调用原有复核、图像、反查工具；它们的所有输出也留在本次目录。继续双法独立初读、有限复核和双方忠实性检查。每次继续个案判断或读取旧盘前，先运行有效期检查；失败后不继续生成答复或写工件：

```text
python <skill-root>/scripts/session_store.py status --session <本次会谈绝对路径>
```

底层chart_bazi_ziwei.py、chart_authoritative.py和liuyao_qimen_fusion.py是兼容/开发工具，直接调用不提供本管理器的同意和留存保障；不能以此绕过正式个案流程。生成固定模拟测试的开发示范命令不是客户会谈授权。

到期后管理器拒绝继续运行该会谈。**没有后台计时清理**：文件不会因时间到自动消失；必须运行下面的清理流程。用户未再次运行工具时，文件可能继续在磁盘。不可宣传“到期即删除”或“绝不保存”。操作系统备份、聊天平台及已导出文件各按自己的规则；普通删除也不是安全擦除。

## 清理预览与执行

用户可随时查看到期会谈清单；清单不读取根目录以外文件，只识别本工具创建的会谈：

```text
python <skill-root>/scripts/session_store.py plan --base <私有根目录绝对路径>
python <skill-root>/scripts/session_store.py cleanup --base <私有根目录绝对路径> --plan-sha256 <刚刚预览的哈希>
```

宿主先展示清理清单和影响，取得用户对这份清单的删除授权再运行cleanup；不能把保存同意等同于任意删除授权。清单内容或文件变化就必须重新预览。若用户明确要求提前结束并删除一个未到期会谈，指定该会谈ID并在两步都加--include-active：

```text
python <skill-root>/scripts/session_store.py plan --base <私有根目录绝对路径> --session-id <s-开头会谈ID> --include-active
python <skill-root>/scripts/session_store.py cleanup --base <私有根目录绝对路径> --session-id <同一ID> --include-active --plan-sha256 <本次预览哈希>
```

清理只删除清单内本工具生成的文件和空会谈目录，保留管理根目录。出现未知文件、用户另存的资料、订单状态、链接/junction/hardlink、权限变化或有管理操作进行时，保留并报告，不能绕过保护强删。不会扫描或清理付费客户端旧订单/远端数据。用户要保留最终答复时先按明确要求导出到管理目录之外；导出的成果不在清理范围。

清理会使会谈原图/追问资料不可恢复，已发送的本地图片引用也可能失效；当前会谈还要看图或追问时不要提前清理。不能承诺清理聊天平台里的历史消息。
