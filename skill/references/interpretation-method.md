# 内部推断方法（v2 — 双盘解读流水线）

> 2026-08-27 升级：排盘已复用 bazi-ziwei-skill（权威，见 chart_bazi_ziwei.py），
> 本文件聚焦**如何从权威原料精准解读**。只约束后台推断，不提供用户话术，
> 用户输出遵循 [consultation-method.md](consultation-method.md)。
> 排盘原料字段：`chart.bazi`（含 enrichment 格局/旺衰/调候/五行/干支关系）+ `chart.ziwei`（十二宫/四化/大限/流年）。

---

## 0. 判盘前必读（防止误读）

1. **排盘是精确的，解读有流派。** 四柱、宫位、星曜由算法层保证；但"这个配置代表什么"存在子平/三合等流派差异，内部等级随流派可信度下调。
2. **先定议题，再找证据。** 用户问什么 → 锁定对应领域（财/官/婚/子/六亲/健康）→ 从两个体系各找证据 → 再聚合。禁止"先排盘后硬套"。
3. **证据驱动，杜绝照抄。** 断语必须能回溯到具体 evidence ID；"早婚""富贵"等标签词，证据只支持到"关系反复""财源有路"时，绝不上探成结果断言。
4. **两个时间轴分开。** 八字用大运（每10年）+ 流年；紫微用大限（每10年）+ 流年。从本命直接锁事件是禁区，时机只留给限运触发，且用"窗口"而非"日"。

### ⛔ 强制数据对齐（2026-08-27 盲评硬伤修正）
解读的每一步**必须从 `chart.bazi` / `chart.ziwei` 的权威字段取值**，不得凭印象、凭常识、凭"好像记得"下笔。盲评证明以下四类是高频硬伤，写断语前必须逐项核对：

1. **当前大限/大运必须查表**：用 `chart.ziwei.gongs[*].daXian.startAge/endAge` 定位"当前年龄落哪一大限宫"，用 `chart.bazi.dayun` 定位当前大运。**禁止凭出生年份估算**——26岁在福德大限(25-34)还是官禄大限，查表才知道，凭感觉必错。
2. **化忌/四化归属必须核对星名**：读 `gong.sihua` 时，`hua` 是哪颗星（化禄/权/科/忌属于哪颗主星或辅星），**直接照抄**，禁止改写成别的星。盲评样例把"文曲化忌"误写"廉贞化忌"即此类。
3. **时间断语必须有证据**：说"入秋前""明年""35岁后"前，必须能在 `dayun[].ganZhi/startAge`、`gong.daXian`、或流年四化里找到对应支撑；**无证据的时间就是凭空注入，禁用**。
4. **大运状态要自洽**："9岁起运，26岁已在某大运"必须有前后一致的大运链条，**禁止说"未入大运"**（除非 age < startAge）。

> 一句话：**限运、化忌、时间、大运，四类数据只认 chart 权威字段，不认记忆。** 任一断语若无法指回某个具体字段，先查表再写，查不到就降级措辞或删除。

## 1. 八字解读（chart.bazi + enrichment）

### 步骤 A — 格局定调（骨架）
读 `enrichment.格局` 的 `primary` 与 `basis`：
- 正官格 / 七杀格 → 事业、责任、规则是主轴。
- 财格 → 财富、资源、享受是主轴。
- 食伤格 → 才华、表达、自由是主轴。
- 印格 → 学识、庇护、名声是主轴。
- 比劫格 → 人际、合伙、竞争是主轴。
- 无成格（格局弱/杂）→ 不以格局锁死，改看旺衰与十神分布。

> 断语起点：格局决定"命主用什么方式成事"。`basis` 是月支透干依据，断语可引用但不得照抄术语。

### 步骤 B — 旺衰定承载（能力）
读 `enrichment.旺衰` 的 `verdict`（偏强/偏弱/中和）与 `score`：
- 偏弱 → 承载财官的能力有限，断"担不担得起"，忌神重时提示压力。
- 偏强 → 能扛事，但过度则断固执、竞争、需泄秀。
- 中和 → 承平，主要看大运流年的引动。
- 结合 `breakdown`（得令/得地/得势）说明"偏弱在哪个环节"，让断语有因果，不是空洞"身弱"。

### 步骤 C — 调候定冷暖（环境）
读 `enrichment.调候用神`：
- 冬生（亥子丑月）需火暖 → 断"寒性体质/早年环境偏冷，需暖局"。
- 夏生（巳午未月）需水润 → 断"燥热，需调候"。
- **绝不用"五行缺什么补什么"替代**；调候是补"气候"，不是补"个数"。
- 调候用神与喜用神不一致时，以调候先行（先解决寒暖，再看强弱）。

### 步骤 D — 十神分布定侧重（领域）
读 `enrichment.五行统计.shiShenGroups`（各五行归入十神类 + 实例数）：
- 财多（尤其透干）→ 财运、物质是敏感领域。
- 官杀重 → 事业压力、规则约束。
- 印旺 → 学习、长辈庇护。
- 食伤旺 → 才华表达、子女、自由。
- 比劫重 → 人际竞争、合伙分财。
- **缺某类**（如 `missing:["金"]` → 印弱）→ 该领域是短板，需后天补足，断语点透。

### 步骤 E — 干支关系定表现（方式）
读 `enrichment.天干关系` 与 `enrichment.地支关系`：
- 天干克/合 → 表"明面"的牵制或结合：
  - **合**（如 丁壬合）→ 两项被"绑"在一起，断牵绊、转化。
  - **克**（如 己克壬）→ 明面压力，断受制。
- 地支刑冲合害 → 表"暗面"的变动：
  - **六冲** → 变动、分离、打破。
  - **六害**（如 卯辰害、丑午害）→ 暗中损耗、摩擦。
  - **拱会** / **暗合** → 隐蔽助力或暗缘。
- 读 `enrichment.整柱`（截脚 / 天地同气）→ 上下关系：天地同气力量足，截脚则受制于坐下。

### 步骤 F — 大运流年定阶段（时间）
读 `chart.dayun`（精确起运 + 每步 ganZhi 的 ganShiShen/zhiShiShen）：
- 每一步大运的十神 → 该阶段主题（走财运=财的主题，走官运=事业主题）。
- **只定"阶段主题与大体吉凶"，不锁具体事件。**
- 当前大运 + 当前流年的十神组合 → 本阶段的具体引动。

## 2. 紫微解读（chart.ziwei）

> ⚠️ 数据读取注意（bazi-ziwei-skill API 坑）：`ziwei.gongs` 数组**按宫位名排序**（[0]命宫 [1]兄弟 … [11]父母），而 `mingGongIndex/shenGongIndex` 是**命宫/身宫的地支索引(0-11)**，不是 gongs 下标。取命宫/身宫必须用 `next(g for g in gongs if g['gong']=='命宫')`，**不要用 `gongs[mingGongIndex]`**（会错取交友宫）。

### 步骤 A — 命宫主星定底色
读 `ziwei.gongs[mingGongIndex]` 的 `mainStars`：
- 紫微/天府 → 领导、稳重、格局大。
- 天机 → 机敏、变动、心思活。
- 太阳/太阴 → 明暗、付出、名望。
- 武曲/七杀/破军 → 刚毅、开创、冲劲。
- 天同/天梁 → 福气、庇护、悠游。
- 廉贞/贪狼 → 欲望、桃花、才艺。
- **无主星（空宫）** → 必须借对宫（三方四正），断"借势、外求、早期不定"。

### 步骤 B — 身宫定中晚年
读 `ziwei.shenGongIndex` 对应宫位的主星与宫位主题：
- 身宫落官禄 → 中晚年重心在事业。
- 身宫落财帛 → 中晚年重心在理财。
- 身宫落夫妻 → 中晚年重心在伴侣/关系。
- 身宫主星是命宫主星的延伸，断"后半生向哪个方向收敛"。

### 步骤 C — 双星组合（不机械相加）
十二宫中两主星同宫（如 太阳天梁、武曲天相、廉贞天府）：
- 看作**一个复合人格的两种面向**，不断成两颗独立星。
- 例：武曲天相 = "刚毅 + 辅佐"的复合，断能打也能配合。
- 例：太阳天梁 = "付出 + 庇护"的复合，断慈善、公共属性。

### 步骤 D — 对宫与三方（空宫借照）
- 命宫 → 对宫（迁移）借照：命主在外界的形象。
- 财帛 → 福德（来因）借照：财的心理根源。
- 官禄 → 夫妻（对宫）借照：事业的助力/阻力来自伴侣。
- **空宫尤其要看对宫三方**，断"此宫借势而来，非先天稳固"。

### 步骤 E — 四化定资源与牵绊
读每宫 `sihua`（化禄/化权/化科/化忌）：
- **化禄** → 该宫领域有资源、顺遂。
- **化权** → 该宫领域有主导权、掌控。
- **化科** → 该宫领域有名声、被看见（名誉缓冲）。
- **化忌** → 该宫领域是牵挂、阻力、需补破。
- 生年四化（命盘先天） vs 大限四化（阶段）分轻重。

### 步骤 F — 限运触发（只放大议题）
读每宫 `daXian`（大限 startAge/endAge）+ `liuNianYear`：
- 看**当前年龄段落在哪一大限宫**，该宫主题被放大。
- 大限四化 + 流年四化叠命/身/大限 → 重点窗口。
- **只提示阶段议题趋势，不锁具体事件**（与八字同）。

## 3. 双盘印证（八字 + 紫微）— 核心增量

两份独立解读完成后，做**交叉对账**（禁止重新独立分析任何一盘）：

### 动作 1 — 主轴印证（定方向）
- 八字主轴：靠 **喜用神/格局优势** 起势，最忌 **忌神/短板**。
- 紫微主轴：重心在 **XX 宫**（命宫+生年四化落宫），中晚年偏向 **YY**（身宫方向）。
- 判定：🟢 同向 / 🟡 互补 / 🔴 方向矛盾（矛盾 → 进冲突规则）。

### 动作 2 — 阶段印证（对时间窗）
把八字大运边界与紫微大限边界放一条时间轴逐段对照：
- 🟢 双盘同吉（八字喜用 + 紫微吉星）→ 高光期。
- 🔴 双盘同凶（八字忌神 + 紫微煞星/化忌）→ 重点防范期。
- 🟡 一吉一凶 / ⚪ 各自独立 → 进冲突规则或按单盘。
- **关键转折年**：换大运+换大限重合（权重×2）、流年四化叠命身限、两盘任一方判"重大事件"的年份。

### 动作 3 — 维度印证（按领域对账）
按用户议题所在维度，引用两盘各自结论：

| 维度 | 八字侧 | 紫微侧 |
|---|---|---|
| 财 | 财星+用神是否生财+大运财气 | 财帛宫+田宅宫+化禄飞临 |
| 官 | 官杀+印护+格局对官需求 | 官禄宫+命宫飞官+化权落点 |
| 婚 | 配偶星/宫+桃花刑冲 | 夫妻宫+大限夫妻+化忌冲夫 |
| 子 | 子女星+时柱 | 子女宫+田子线 |
| 六亲 | 印/比劫状态+年月柱 | 父母宫+兄弟宫+父疾线 |
| 健康 | 日主+忌神克脏腑+调候缺失 | 疾厄宫+父疾线+化忌冲疾 |

判定：**A 印证 B**（两盘同说，可信度↑）/ **A 修正 B**（B 被 A 加条件或时间窗）/ **A 反驳 B**（相反 → 进冲突规则）。

### 冲突判定规则（4 条，不和稀泥）

1. **时间窗冲突**（同段一吉一凶）：看煞星程度（羊陀火铃化忌齐聚 → 凶优先）；看流年是否双重命中（两盘点名 → 凶坐实）；紫微仅主星弱无煞 + 八字忌神当令 → 八字优先。
2. **方向冲突**（喜用神 vs 星性反向）：30岁前听紫微的"势"（星曜冲势）；30–60岁听八字的"体"（喜用根底）；60岁后两盘共同信号才作数。
3. **力度冲突**（一强一弱）：听强信号，弱信号一句话带过，不凑字。
4. **完全对立**：明说"信号矛盾"，该条置信度标低，建议以实际反馈为准。

## 4. 证据分级与断语生产（对接 consultation-plan-schema）

- 每个结论 `conclusion` 必须填 `bazi_evidence_ids` + `ziwei_evidence_ids`（来自 chart.bazi/ziwei 能回溯的具体信号）。
- `bazi_level` / `ziwei_level` = `high|medium|low|none`，由各自证据强度定：
  - **high**：格局清/旺衰明确 + 双盘同向无反证、或生年四化+主星强信号。
  - **medium**：单盘强信号、或双盘互补但各有条件。
  - **low**：信号弱、流派存疑、需借照。
- `agreement` = `same|complementary|conflict|single`：
  - **same**：双盘同议题同方向 → 可信度最高。
  - **complementary**：一讲内在动机一讲外部表现 → 可同立。
  - **conflict**：同议题反方向 → 按冲突规则判定，保留反证。
  - **single**：仅一体系证据足够。
- **双高同断**：`agreement=same` 且两边均 `high` 且无同级反证 → `delivery` 强制 `direct`，verdict 直接断言、无概率词。
- 其余按强度映射 `probable` / `tentative`；有实质性反证时强制降级。
- `counter_evidence_ids` 主动记录同题反证；有同级冲突不得标 `same`。

## 5. 输出隔离

- 内部推断先写 `consultation-plan.json`（见 consultation-plan-schema.md），由校验器控制措辞。
- 用户答复**不得直接读取或复述**本文件的术语、体系名、证据链 ID。
- 命盘外变量（风水、姓名、阳宅）不进入本推断。
- 每轮结论自评置信度（高/中/低），标在 `conclusions[].delivery` 与内部备注。

---

> 一句话：拿到权威双盘原料后，先各按"格局→旺衰→调候→十神→干支→大运"和"命宫→身宫→组合→三方→四化→限运"完成单盘解读，再做三动作交叉印证，按冲突规则消歧，最后映射到 high/medium/low 与 direct/probable/tentative 出断。
