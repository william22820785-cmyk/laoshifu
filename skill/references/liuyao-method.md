# 六爻问事方法（V2.0 六爻+奇门双法同参）

## 使用边界

六爻用于一事一占，回答某件具体事情能否成、何时有变化、哪里受阻、怎样取舍。人的长期命运、性格底色、婚姻结构和十年阶段仍走八字紫微，不用六爻代替。

同一件事已经起卦后，不因答案不合心意立即重起。只有问题实质改变、关键条件改变，或经过一段时间出现新局面，才另起一卦。

## 双法同参

算事时内部同时调用六爻和奇门遁甲两个体系：
- 六爻负责起卦、动变、六亲、世应和旺衰。
- 奇门遁甲负责排盘、用神定位、格局、生克和空间方位。
- 两法方向一致且强度均为高时，断语必须直接肯定，不容含混。
- 两法相左时，先检查输入条件，若无误则如实说明两种可能，不强行统一。
- 融合过程完全在后台，用户只看到统一断语和标准六爻卦图。

## 起卦前两问

第一问先把事情问实。宽泛的"问事业、问感情、问财运"不能起卦，要知道用户究竟在问哪件事、对象是谁、想知道结果还是时间。每轮只问一个问题，不把问题拆成表单。

第二问只选择起卦方式：

> 这件事已经说清了。你想按此刻起卦，还是凭第一念报三个数？

- 时间起卦：用户确认后，以确认当刻和用户所在地时区起卦。不要拿用户最初提问的旧时间，也不要依赖运行机器的默认时区。
- 报数起卦：让用户凭第一念报三个正整数，依次定上卦、下卦、动爻。不要暗示吉利数字，不替用户选数。

两种方法都显式记录起卦年月日、时分和用户所在地时区；报数决定卦象，起卦时刻仍决定月日旺衰。

不使用三钱法、蓍草法、随机数或其他入口。

## 取用方向

先把所问事项映射到具体对象，再选用神。不要只按宽泛分类机械套用。

- 工作职位、升迁、求职、官非、疾病压力：通常看官鬼。
- 钱款、收入、货物、交易回款、男问伴侣：通常看妻财。
- 合同、文书、证件、房屋、学业成绩、消息凭据：通常看父母。
- 子女、孕育、医药解忧、消灾结果：通常看子孙。
- 同行、合伙人、竞争者、朋友、资金分夺：通常看兄弟。
- 女问伴侣通常看官鬼；婚恋还要结合世应、动爻和所问对象的现实关系。

同一问题可能有主次两类，例如问"合同能不能签并收到款"，父母为合同，妻财为款项。先按用户最想知道的结果定主用，再把另一类作为条件，不可含混成一个答案。

## 奇门取用映射

奇门遁甲根据事项类型定位用神，与六爻取用方向并行对照：

- 官非、升迁、求职、事业变动：看开门、直符、官鬼落宫。
- 财利、交易、求财、男问婚恋：看生门、戊己落宫、妻财落宫。
- 文书、契约、考试、房产、学业：看景门、丁奇、父母落宫。
- 出行、寻人、消灾、子女：看休门、六合、时干落宫。
- 婚恋女问男、合作纠纷：看六合、乙庚落宫、兄弟落宫。
- 寻物、遗失、盗窃、失联：看时干落宫、玄武落宫、失物类象。

内部两套用神分别生成证据，融合后的 `agreement` 再决定出断语气。奇门用神绝不对外展示。

## 七成结构

结构判断约占七成，依次检查：

1. 用神是否出现，落在哪一爻，是否持世、临应、伏藏或空破。
2. 世爻代表用户，应爻代表对方、目标或外部环境；看双方生克、合冲、强弱与动静。
3. 用神得月日扶助还是受制，是否发动，变爻回头生克、化进化退或化空。
4. 元神能否生用，忌神是否制用，仇神是否助忌；伏神能否出伏。
5. 六合六冲、反吟伏吟、三合、暗动、月破日破等是否改变事情节奏。
6. 应期只给有盘面边界的时间窗口，如填空、出空、逢合、冲开、值临，不凭空编造精确日期。

强弱不能单点下结论。至少结合用神、世应和动变三层；遇到直接反证要写入计划，降低语气或说明条件。

## 三成卦意

本卦说事情眼下的总体处境，动爻爻辞说变化关节，变卦说后势落点。三者约占三成，用来校正大方向，不得用一句卦辞压过七成结构，也不得脱离用户问题讲泛泛人生哲理。

引用古义时先转成现代处境。正文不堆原文，不讲"某爻曰"，只说这件事现在像什么、会往哪里变。

## 出断顺序

1. 从 fusion.json 读取 `agreement` 和 `conclusions`
2. 原样显示 `fusion.diagram`（标准六爻卦图 Markdown 表格）
3. 前两三句直接回答用户最关心的成败或走向
4. 给变化窗口，并说明促成条件与拖累条件
5. 给一两件与此事直接相关的行动
6. 最后用不超过四分之一篇幅点出取舍

断语正文不出现用神、旺衰、世应、六亲、六神、奇门九宫、空亡宫等后台词。用户可以看到标准卦图，但看不到内部推断链。

### 双法同断规则

- agreement.same + 判断 delivery=firm：直接断言，删除"可能、大概、多半"等退让词
- agreement.conflict 有内容：说明"有一样我看得不是特别准——"，列出分歧维度
- 从不提及"六爻"或"奇门"两个词
