## 多语言体验

固定示例支持中文、英文、西语和葡语：`python scripts/preview_examples.py --example contract --lang en`。实际解读跟随用户语言；计算标签、证据字段保留原文供核对。海外出生地使用历史时区与真太阳时，夏令时歧义先核实。见[多语言与跨文化规则](references/INTERNATIONAL.md)。

对外讲解的专业名词出现次数，占全部名词出现次数须低于14%；按实际语言审读并绑定名词清单，不按字符或总字数稀释。详见[文化叙事与计数规则](references/CULTURAL-NARRATIVE.md)。
